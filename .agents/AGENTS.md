# ReactFlow API Usage

Before writing, modifying, or referencing any ReactFlow API, components, hooks, or
configuration (e.g. ``ReactFlow``, ``useReactFlow``, ``Handle``, ``NodeTypes``, ``EdgeTypes``,
``applyNodeChanges``, ``applyEdgeChanges``, etc.), you MUST fetch the latest docs first:

```
fetch https://reactflow.dev/llms.txt
```

Do **not** rely on training-data knowledge for ReactFlow. The library changes
frequently and training data is often stale. Always use the live documentation
from the URL above before generating or reviewing any ReactFlow code.
